# Changelog

## 0.1.0 (unreleased)

First public preview.

- Claude Sessions list in the Explorer: Needs you, Running, Done and Idle, with time in the current state.
- Why a session is waiting (e.g. "Permission to run: npm test").
- Your prompts per session, newest first, with full text and image previews on hover. Copy a prompt from the right-click menu.
- Open or focus a session's Claude Code tab.
- "Go to Next Session That Needs You" (Cmd/Ctrl+Alt+W).
- Status bar count with a summary card.
- One-time, consent-based hook setup with backup; "Remove Session Tracking"; automatic cleanup on uninstall.
- "Check Setup" report.
